# Raneto Example

Raneto is a free, open, database-free Markdown-powered knowledge base engine for Node.js. 

Raneto is a pre-configured, lightweight template designed to help you run Raneto as a standalone npm library without downloading the core framework source code. If you prefer to customize the core engine directly, please visit the [Main Raneto Repository &rarr;](https://github.com/ryanlelek/Raneto)

## Getting Started

Clone this repository and launch your local server by running the following commands in your terminal:
```bash
git clone https://github.com/raneto/example.git
cd example
npm install
npm start 
```

## Next Steps

1. Visit http://localhost:8080 in your browser to see your running knowledge base.

2. Add, remove, or edit the Markdown files inside the `content/` directory to manage your wiki articles.

3. Refer to the official installation guide at https://docs.raneto.com for advanced configuration, security settings, and deployment options.
